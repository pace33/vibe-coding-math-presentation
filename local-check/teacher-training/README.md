## 교과서 탐구에 근거한 발표 개정 (2026-11-23)

- 전체 42장. **교과서 근거 → 실제 프롬프트·수정 → 수업 도구 → 수업 적용** 순서로 구성합니다.
- 사회과 **[4사09-01]** 지역 문제 조사·합리적 해결: 지역 뉴스·신문과 공공기관 누리집으로 자료를 수집하는 교수학습 활동 근거.
- 사회과 **[4사09-02]** 자연환경·역사·문화·생산물 이해: 지역정보를 여섯 분야로 재구성한 설계 근거(여섯 분야 자체가 교과서의 정식 분류는 아님).
- 국어과 **[6국06-02]** 뉴스·정보 매체의 신뢰성 평가: 출처·작성 주체·근거 비교 활동의 직접적인 근거. 뉴스 신뢰성 평가는 국어 성취기준이며 이를 사회의 지역 문제 탐구와 **교과 연계**합니다.
- 출처는 [국립특수교육원 2022 개정 공통 교육과정 사회과 성취수준 자료](https://www.nise.go.kr/ebook/src/viewer/download.php?host=main&no=1&site=20240819_172144) 및 [경기도교육청 [6국06-02] 자료](https://www.goe.go.kr/resource/old/BBSMSTR_000000030222/BBS_202504210452515481.pdf)에서 확인.
- 교과서 출판사별 판본과 쪽수는 확인되지 않아 **교과서 페이지 본문을 인용하지 않았습니다.** 해당 성취기준과 교수학습 참고자료임을 분명히 합니다.
- 최초 앱 개발 프롬프트 원문 전문은 확보되지 않아 처음 설계 취지 문장은 **재구성**으로 표시합니다.
- 대신 실제 제작 대화에서 확인한 요구 문장: 기본정보를 카드에 바로 표시, 세부 분야 뉴스 검증→게시판 연결, 실제 뉴스 제공자 구글/빙 구분, 축제·견학 추가를 **실제 요청 원문**으로 구분합니다.
- 개발 과정의 이미지들은 **재구성 시연 이미지**로 유지하며 실제 대화 스크린샷이라고 표기하지 않습니다.
- 참가자가 직접 앱을 만드는 실습은 실시하지 않습니다.
- 기존 학생용 웹앱 `/local-check/student/`와 원본 발표자료 루트 경로는 수정하지 않습니다.

## 조작

- ← / →, PageUp / PageDown: 전후 슬라이드

- O: 목차
- N: 발표자 메모
- F: 전체화면
- 하단 'PDF 저장': 전체 슬라이드 인쇄·PDF 저장

## 자료 정확성 및 주의

- 제작 이미지는 실제 `우리 지역 탐정`의 메뉴·기능·수정 기록을 바탕으로 재구성한 **교육용 예시 이미지**입니다. 실제 뉴스 결과 스크린샷으로 표시하지 않습니다.
- 학생용 웹앱은 충북 11개 시·군, 6개 분야, 뉴스 기사 검색·검증 및 탐정 카드 저장을 제공합니다. 게시판은 기기별 localStorage 방식이며 학급 공동 서버 게시판은 아닙니다.
- 뉴스 서버는 구글 뉴스 RSS와 빙 뉴스 RSS 중 먼저 유효한 응답을 반환한 제공처를 사용합니다. 표시된 정보는 검증 완료가 아닙니다. 외부 링크·방문예약·실시간 운영 상태는 현장에서 원문 확인이 필요합니다.
- 교실 적용 슬라이드의 ‘쉬운 질문 틀, 시각 지원, 다양한 표현’은 **교사 수업 설계 제안**이며 모든 기능이 웹앱에 구현되어 있다고 주장하지 않습니다.
- 교육과정 자료: 교육부 「2022 개정 교육과정 확정·발표」 https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&m=020402&opType=N
- 디지털 소양 자료: 경기도교육청 「2022 개정 교육과정의 디지털 소양 내용 요소와 반영 방향」 https://www.goe.go.kr/resource/old/BBSMSTR_000000000126/BBS_202402261130401580.pdf
