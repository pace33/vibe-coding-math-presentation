# 로컬체크 탐험대 — 초등 사회과 지역정보 탐구

## 학생용 웹페이지
https://pace33.github.io/vibe-coding-math-presentation/local-check/student/

기존 GitHub Pages의 \`local-check/student/\` 경로에 올리는 HTML/CSS/JS 웹앱입니다. 로그인과 별도 설치가 필요하지 않습니다.

## 수업 목표
학생이 **지역 대표 사례 발견 → 실제 공공기관 공지·기사 원문 확인 → 자료 비교·검증 → 근거 있는 결론 → 발표**의 사회과 탐구 흐름을 직접 수행합니다. 자동 채점·정답 표시보다 학생의 검증 이유와 근거 기록을 우선합니다.

## 기능
- 충북 11개 시·군별 공식 출처가 연결된 대표 탐구 사례 14개: 학생에게 익숙한 축제·문화·인구·지역 소식
- 초등 3~4학년, 5~6학년, 읽기 지원이 필요한 학생을 위한 수준 선택 / 질문 음성 읽기
- 5단계 학습 흐름: 예상하기, 실제 자료 찾기, 두 자료 비교하기, 판단하기, 탐구 결과 공유
- 최근 기사·공지 목록은 \`latest.json\`에서 불러오며 제목, 발표기관, 날짜, 원문 링크와 함께 ‘검증 전’으로 표시
- 최근 기사 제목을 선택하면 관련 지역·주제의 **공식 자료집 원문과 유사한 다른 기사**를 비교자료 후보로 제시합니다. ‘비교자료로 선택’ 클릭 시 주소만 채워지고, 학생은 원문을 읽고 근거를 적어야 합니다.
- 같은 주제의 후보가 없으면 공식기관 및 뉴스 검색 링크를 제공합니다. **기사 본문 자동 분석이나 진실 여부 자동 판정은 구현되지 않았습니다.**
- 학생의 기사 제목·URL 직접 붙여넣기 입력칸은 제거했습니다. 최근 뉴스 카드의 ‘이 뉴스 확인하기’로 곧바로 탐구를 시작합니다.
- 선생님은 주제 카드의 **링크 복사** 기능으로 QR코드용 URL을 학생과 공유 가능
- 학생 탐구 카드는 복사, TXT 내려받기, 브라우저 인쇄/PDF 기능 지원
- 학생 이름/학교 정보 수집 없음. 공유 전 학습 기록은 학생 기기의 localStorage에만 보관하며, 친구와 공유한 링크에는 탐구 카드 내용이 포함됩니다.

## 자료의 시점과 자동 갱신
- \`data.js\`: 2026-11-19까지 확인한 **저장 사례**입니다. 출처 링크는 후속 검증이 필요합니다.
- \`latest.json\`: 초기에는 2026-11-19 기준 수동 선택한 실제 최근 공식자료 7건을 보여 줍니다.
- \`.github/workflows/localcheck-news.yml\`: GitHub Actions가 매일 한국 시각 약 오전 7시에 \`tools/update_news.py\`를 실행하도록 등록했습니다. 공개 Google 뉴스 RSS에서 충북 11개 시·군의 최근 45일 헤드라인·발행기관·날짜·링크만 모아 파일을 갱신합니다.
- 실제 첫 자동 실행 성공 및 GitHub Pages 반영은 아직 검증되지 않았습니다. Google 뉴스 RSS 제공 상태나 GitHub Actions 저장소 정책에 따라 갱신이 실패할 수 있습니다. 실패 시 기존 자료를 유지하며, 사용자는 ‘최근 1개월 기사’ 검색 버튼을 통해 직접 조사할 수 있습니다.
- 자동 수집 자료는 진실 판정이 아니므로, 학생이 **반드시 원문 및 공식기관 공지와 대조**해야 합니다.

5. 7분: 탐구 카드를 인쇄·공유하고 새로운 탐구 질문 만들기

## 우리 반 탐정 게시판 (카드 공유)
- 학생이 `나의 탐정 카드 완성하기`를 누르면 결과가 현재 기기의 **내 게시판**에 자동 보관됩니다.
- `친구에게 카드 공유`를 누르면 **카드 내용을 포함한 공유 링크**가 복사됩니다. 친구는 이 링크를 열어 기사 제목·근거·판단·출처를 확인한 뒤 `내 게시판에 담기`를 선택할 수 있습니다.
- 게시판에는 직접 작성한 카드와 친구에게 받아 보관한 카드가 나타납니다. 카드 상세 보기·다시 공유·내 기기에서 삭제·JSON 내려받기가 가능합니다.
- **다른 학생의 결과가 자동으로 한곳에 모이는 공용 학급 게시판은 아닙니다.** 현재 GitHub Pages에서는 데이터베이스가 없고, 교사가 각 카드 링크를 받아 자기 기기의 게시판에 담아 모으는 방식입니다.
- 링크의 `#card=...` 부분은 암호화가 아닌 데이터 인코딩입니다. 링크를 받은 누구나 결과를 읽을 수 있으므로 학급 내에서만 공유하고 이름·학교·연락처·학번·건강 정보 등 개인정보를 절대 적지 마세요. 카드 공유 시 전화번호 및 이메일 형식 일부를 검사하지만 모든 개인정보를 자동 탐지하지는 못합니다.
- 공개 학급 게시판이 필요한 경우 Firebase·Firestore 등 별도 데이터베이스와 **교사 승인, 학급별 접근권한, 게시물 삭제, 보존 기간** 설정을 마친 후 연결해야 합니다. 학생 작성 내용은 사실 검증 확정 결과가 아닙니다.


## 우리 지역 기업·산업 탐구 (2026-11-19 추가)
- 충북 11개 시·군의 공식 사업장 자료를 확인한 **대표 기업·산업 사례 12건** 제공 (\`businesses.js\`).
- 지역과 키워드로 회사·공장·업종을 찾고, 카드에서 **무엇을 만드는지** 쉬운 말로 확인할 수 있습니다.
- '이 기업 조사하기'를 누르면 기존 탐구 활동으로 이어져 **본사와 지역 사업장 구별, 생산품 확인, 기업 소식과 공식 공시·기관 발표 비교**를 수행합니다.
- 각 회사 카드에서 **소개 자료 원문**과 **최근 90일 기업 뉴스 검색**을 열 수 있습니다.
- 선택한 뉴스 제목에 같은 지역 기업명이 있으면 기업 관련 자료를 비교 후보로 제시합니다. 기사와 업체 자료의 내용이 실제 일치하는지는 학생이 원문을 읽어 판단해야 합니다.
- 기업은 홍보 대상이 아닌 **지역사회와 산업의 관계를 살펴보는 탐구 소재**입니다. 본사 주소, 공장 위치, 사업 진행 단계, 생산품은 항상 기준 날짜를 확인합니다.
- 현재 사업장 사례는 저장형 자료이며, **기업정보 전체나 실시간 기업 DB를 자동 탐색하는 기능은 아닙니다.**
