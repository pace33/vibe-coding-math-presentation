# 로컬체크 | 학생용 우리 지역 탐정

웹사이트: https://pace33.github.io/vibe-coding-math-presentation/local-check/student/

## 메뉴

| 메뉴 | 학생이 하는 일 |
| --- | --- |
| 📰 뉴스 찾기 | 충북 11개 시·군 선택 → 뉴스 검색 → 기사 검증 |
| 🗺️ 우리 지역 | 기본 정보 / 자연환경 / 생활시설 / 산업과 경제 / 역사와 문화 / 지역문제 → 뉴스·공공자료 비교 |
| 🗂️ 탐정 게시판 | 내가 만든 카드 및 친구 링크로 받은 카드 확인 |

- 모든 메뉴에서 같은 지역 선택 기능을 사용합니다.
- 첫 화면은 지역 선택·뉴스 검색·최근 뉴스 중심으로 표시합니다. ‘우리 지역’ 메뉴에서는 교과서 기준 6개 분야를 선택합니다.
- 6개 분야를 선택하면 지역별 기초정보 카드와 공식 자료 링크를 즉시 보여줍니다. 음성군 자연환경은 가섭산·응천·원남저수지·기후평년값·봉학골 산림욕장 자료를 우선 연결했습니다. 수치를 확인하지 못한 항목은 임의의 값을 만들지 않습니다.
- 뉴스 검색은 **뉴스 찾기**와 **우리 지역 → 지역문제**에서만 실행합니다. 다른 기초정보 분야는 실제 지명·시설명·기업명 등을 카드로 먼저 보여줍니다.
- 검색어를 2글자 이상 입력하면 약 0.65초 입력 대기 후 새 Google 뉴스 RSS 검색을 자동 시작합니다. 자동 검색 결과는 검색창 **바로 아래** 표시되며, 이전 검색은 취소됩니다.
- 검색어가 없으면 저장된 최근 뉴스 4개를 보여줍니다. 검색 버튼이나 Enter 키로 즉시 검색할 수도 있습니다.
- 구글 뉴스 더 보기 버튼은 기본 최근 뉴스 4개 아래에 남겨두었습니다. 자동 검색이 시작되면 최근 목록은 감추고 검색 결과를 보여줍니다.
- 산업과 경제에서는 대표 기업과 중소기업·지역 업체 자료를 구분합니다. 한 번에 보여주는 기업은 6곳이며, ‘더 보기’로 펼칠 수 있습니다.
- 자연환경·역사문화·기업 등 변동이 적은 명칭은 지역별 실제 사례로 보여주며, 확인되지 않은 세부 링크는 지역명·항목을 채운 구글 검색으로 대체합니다.
- 인쇄·글 저장·자세한 근거 기록은 접힌 메뉴로 옮겨 기본 화면을 간단하게 유지합니다.

## 뉴스 조회

- `live-news.js`에서 운영 중인 전용 뉴스 검색 서버를 호출합니다. 서버가 Google 뉴스 RSS를 직접 가져오며 앱 안에 기사 제목·언론사·날짜·원문·검증 버튼을 보여줍니다. 무료 공개 RSS 중계 서비스를 브라우저에서 호출하지 않습니다. 서버 구성은 `../server/README.md`를 참고하세요.
- 외부 서비스 요청 실패 시 `latest.json`에 저장된 뉴스로 대체하며 저장된 자료임을 명시합니다.
- 수집 작업 `tools/update_news.py` 및 GitHub Actions를 통한 자동 갱신은 기존대로 유지합니다.
- 원문 전체를 앱에 복제하거나 검색 결과를 사실로 확정하지 않습니다.

## 검증

1. 뉴스·기업·지역 주제를 선택합니다.
2. 제목·지역·등록 자료에 근거해 관련 공식자료나 다른 언론기사를 자동으로 추천합니다. RSS 검색은 외부 서비스 상태에 따라 실패할 수 있습니다.
3. 학생이 실제 원문을 비교한 뒤 **맞아요 / 달라요 / 모르겠어요**를 선택합니다.

**중요:** AI 모델을 사용한 기사 본문 자동 분석이나 진위 자동 판정은 구현되지 않았습니다. 관련 기사들이 같은 보도자료를 인용했을 수도 있으므로 학생이 원문과 근거를 확인해야 합니다.

## 탐정 게시판

- 학생의 검증 결과는 해당 기기의 `localStorage`에 저장됩니다.
- 공유 링크를 받은 친구는 카드 내용을 읽고 자신의 기기에 저장할 수 있습니다.
- **학급 전체 카드가 서버에 자동 수집되는 공용 게시판이 아닙니다.**
- 공유 링크에는 카드 내용이 포함됩니다. 실명·학번·학교명·연락처 등 개인정보를 기록하지 마세요.

## 데이터 파일

- `data.js`: 지역 탐구 대표 사례.
- `regional-inquiries.js`: 사회 교과서 기준 6개 지역 정보 분야.
- `regional-basics.js`: 11개 시·군의 기초정보 카드 데이터, 음성군 자연환경의 출처 연결.
- **생활시설 세부 링크(2026-11-21 정리):** 충북 11개 시·군에서 행정기관·안전시설·교육문화시설·교통 4개 카드가 각각 별도 공식 상세 자료로 연결됩니다. 버튼에는 ‘버스정보’, ‘119안전센터’ 등 대상 자료를 명시합니다. 일부 시·군은 대표 기관 한 곳의 예시 페이지를 제공하며, 외부기관의 주소 변경 가능성이 있어 개별 접근성을 주기적으로 점검해야 합니다.
- `businesses.js`: 지역 대표 기업·사업장 사례 12건.
- `small-businesses.js`: 중소기업·지역 업체 사례 13건.
- `latest.json`: 최근 뉴스 캐시. 발행일 및 마지막 갱신일은 파일을 확인하세요.
- `app.js`: 메뉴·검색·검증 흐름.
- `board.js`: 기기별 탐정 카드 저장 및 링크 공유.
- `style.css`: 공통 스타일. 화면별 증분 디자인 대신 단일 통합 스타일 사용.

학교에서 안정적으로 운영하려면 RSS 중계 서비스의 요청 한도·개인정보 처리·접근성·브라우저 지원을 점검해야 합니다.

## 분야별 상세 링크 및 검색 대체 (2026-11-21)

- 충북 11개 시·군 × 지역 정보 6개 분야에서 사용되는 카드의 링크를 항목별로 점검했습니다.
- 해당 항목의 세부주소가 존재하는 경우 그 링크를 유지합니다. 확인된 상세 페이지로 충주호, 제천 의림지, 옥천 대청호 안터지구, 괴산 산막이옛길, 단양 도담삼봉을 보완했습니다.
- 시군청·관광 포털의 **첫 화면만 연결되던 카드**는 지역과 항목이 입력된 **구글 검색 결과**로 전환합니다. Google이 검색한 결과는 검증된 정보가 아니므로 발행기관·기준 날짜를 직접 확인해야 합니다.
- 직접 페이지 링크에도 '링크가 안 열리면 구글 검색' 대체 버튼을 표시합니다. 카드 하단의 '구글 검색어 직접 바꾸기'를 열어 검색어를 수정할 수 있습니다.
- 이 방식은 외부 사이트의 404 오류를 실시간 자동 감지하는 방식이 아닙니다. 외부 링크가 주소 변경으로 열리지 않으면 Google 대체 검색을 사용합니다.
- 최근 뉴스 조회·검증·탐정 게시판은 기존대로 유지하며, 지역 기본정보 보기에서 자동 뉴스 검색은 실행하지 않습니다.

## 자연환경·역사문화 실제 장소명 및 지역문제 검색 (2026-11-21)

- `regional-landmarks.js`: 충북 11개 시·군별 실제 자연환경 대표 장소 44개와 역사·문화 장소 35개를 카드에 기본 표시합니다. 산·하천·강·저수지의 명칭, 문화유산·유물·박물관·미술관·역사 장소를 기초정보로 제공합니다.
- 세부 링크가 확인되지 않은 장소는 지명과 항목으로 구글 검색합니다. 장소의 현재 운영 여부와 관람 시간은 원문에서 확인합니다.
- **지역문제**는 고정 정보 카드가 아닌 최신 뉴스 중심입니다. 지역을 선택하면 환경 관련 뉴스를 조회하고, 환경·교통안전·교육복지·지역생활 주제 버튼이나 검색어 입력으로 기사를 찾을 수 있습니다.
- 검색 연결이 실패하면 저장 기사 또는 구글 뉴스 원본 검색으로 안내하며, 저장 기사를 최신 결과라고 표시하지 않습니다.

## 대표기업·사업장 확충 (2026-11-21)

- `additional-businesses.js`: 충북 11개 시·군에 공식 기업 소개·2026년 공시·지자체 기업현황 등을 근거로 대표기업·사업장 24개를 추가했습니다. 기존 대표기업 12개 및 지역 중소기업·업체 13개는 그대로 유지합니다.
- 시·군별로 청주(2), 충주(2), 제천(2), 보은(2), 옥천(2), 영동(2), 증평(2), 진천(3), 괴산(2), 음성(3), 단양(2)을 추가했습니다. 전체 총 49개 기업·사업장 사례입니다.
- 기업 자체와 **해당 지역에 위치한 공장·사업장**을 구별하며, 본사가 다른 지역일 수도 있음을 학생에게 안내합니다. 제약·배터리·반도체·식품·가구·금속 재활용·건축재 등 업종 다양성을 고려했습니다.
- 출처가 되는 기업 공식 페이지·공공기관 원문을 카드의 '자료 확인'에 연결하고, 원문 주소 변경 시 검색할 수 있도록 관련 공공자료 검색 링크를 보조 근거로 제공합니다.
- '대표 기업'은 규모나 매출 순위의 공식 인증이 아니라 **초등 사회 지역 산업 탐구용 대표 사례**라는 뜻입니다. 기업과 공장 운영 현황은 시점에 따라 변동될 수 있습니다.

## 화면 간소화 (2026-11-21)

- 3개 큰 메뉴와 6개 지역 정보 분야는 유지하면서 메뉴의 중복 보조 설명 9개, 첫 화면의 반복 제목·안내글, 사용하지 않는 숨김 추천 영역을 정리했습니다.
- 주요 메뉴·분야 탭 높이와 화면 간격을 줄이고 자연환경·역사문화 카드는 데스크톱 2열, 모바일 1열로 표시합니다.
- 기초정보 카드에서는 첫 번째 자료 링크만 바로 표시하고, 구글 검색어 수정·대체 검색·부가 링크는 **추가 자료·검색**에 모았습니다. 자료 출처 표시는 유지합니다.
- 산업과 경제에서는 중복된 기업 기초정보 카드를 제거해 **기업 목록 하나**로 통일하고, 지역별 농산물·특산물은 기업 목록 아래 별도 카드로 표시합니다.
- 3단계 검증의 실제 제목과 기록 절차는 유지하되 중복된 단계 표시와 문장을 줄였습니다. 탐정 게시판의 공유·기기 저장 안내는 유지합니다.

## 기본정보 즉시 보기 (2026-11-21)

- ‘우리 지역 → 기본 정보’의 4개 카드(위치·행정구역·인구·면적)는 이제 **11개 시·군 모두 실제 값을 바로 표시**합니다. 이전의 ‘읍면동’, ‘통계 기준 확인’ 같은 값 자리표시자 대신 확인된 수치와 명칭을 사용합니다.
- **인구**: 행정안전부 주민등록 인구통계(2026-10-31 기준, 외국인 제외). 11개 시·군 합계 1,602,382명으로 충북 총계와 일치합니다. [공식 원문](https://jumin.mois.go.kr/statMonth.do)
- **면적**: 충청북도 2025년 말 지적통계 기준으로 ㎢ 단위 반올림한 약값. [공공데이터포털](https://www.data.go.kr/data/3075683/fileData.do)
- **행정구역**: 시·군 공식 현황을 사용하며 2026년 3월 음성군 대소읍 승격(3읍·6면)을 반영했습니다. 청주시는 4개 행정구도 안내합니다.
- **위치**: 충북 내부의 방향(서부·북부·남부 등)을 간단히 표기하며, 공식 행정구역 지도 링크를 제공합니다.
- 카드에는 출처 링크와 기준 시점을 표시하며, 외부 페이지가 열리지 않을 때를 대비한 검색 기능은 ‘추가 자료·검색’에 유지합니다. 값이 자동 업데이트되는 것은 아닙니다.

## 지역 정보 분야별 뉴스 검증과 탐정 게시판 이동 (2026-11-21)

- ‘우리 지역’의 6개 세부 분야에서 **이 분야 뉴스 검증하기** 버튼을 사용하면, 선택한 시·군과 분야를 유지한 채 관련 뉴스 검색 결과가 해당 화면 아래에 나옵니다.
- 기본 정보·자연환경·생활시설·산업과 경제(농산물)·역사와 문화 카드에는 **이 정보 관련 뉴스 검증** 버튼을 두어 개별 항목(예: 인구, 무심천, 박물관)을 바로 뉴스로 탐구할 수 있습니다.
- 지역문제는 기존 환경·교통안전·교육복지·지역생활 주제 검색과 함께, 동일한 검증/게시판 이동 버튼을 제공하도록 했습니다.
- 검색 결과에서 **검증하기** → 출처·근거·기사 비교 → **탐정 카드 완성하기**를 선택하면 기존 탐정 게시판에 카드가 저장됩니다.
- 모든 세부 분야에 **탐정 게시판 보기** 버튼을 제공하며, 탐정 게시판에서 돌아오면 원래 지역·세부 분야 화면으로 복귀합니다.
- 탐정 게시판 저장은 브라우저의 `localStorage` 기준입니다. 서로 다른 기기의 작성 결과가 학급 공용 게시판에 자동으로 모이는 구조는 아닙니다.
- 새 기능은 기초정보를 자동으로 참이라고 판단하지 않습니다. 학생이 실제 뉴스 원문과 공식 자료를 비교해 판단합니다.


## 역사와 문화: 지역축제·예술 행사 (2026-11-21)

- 기존 문화유산·박물관·미술관·역사 장소 카드를 유지하면서 충북 11개 시·군별 대표 축제 1개와 예술·공연 축제 1개를 추가했습니다(총 22개 카드).
- regional-landmarks.js의 FESTIVALS 자료를 해당 지역 역사문화 카드 아래에 연결합니다. 21개는 시군청·공공기관·행사 주최기관의 상세자료로 연결하고, 제천한방천연물산업박람회는 지역명이 포함된 구글 검색으로 안내합니다.
