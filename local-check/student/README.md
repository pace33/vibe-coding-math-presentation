# 로컬체크 탐험대 — 초등 사회과 지역정보 탐구

## 학생용 웹페이지
https://pace33.github.io/vibe-coding-math-presentation/local-check/student/

기존 GitHub Pages의 \`local-check/student/\` 경로에 올리는 HTML/CSS/JS 웹앱입니다. 로그인과 별도 설치가 필요하지 않습니다.

## 수업 목표
학생이 **지역 대표 사례 발견 → 실제 공공기관 공지·기사 원문 확인 → 자료 비교·검증 → 근거 있는 결론 → 발표**의 사회과 탐구 흐름을 직접 수행합니다. 자동 채점·정답 표시보다 학생의 검증 이유와 근거 기록을 우선합니다.

## 기능
- 충북 11개 시·군별 공식 출처가 연결된 대표 탐구 사례 14개: 학생에게 익숙한 축제·문화·인구·지역 소식
- 초등 3~4학년, 5~6학년, 읽기 지원이 필요한 학생을 위한 수준 선택 / 질문 음성 읽기
- 5단계 학습 흐름: 예상하기, 실제 자료 찾기, 두 자료 비교하기, 판단하기, 탐구 결과 공유
- 최근 기사·공지 목록은 \`latest.json\`에서 불러오며 제목, 발표기관, 날짜, 원문 링크와 함께 ‘검증 전’으로 표시
- 최근 기사 제목을 선택해서 새 탐구를 시작할 수 있으나, **기사 본문을 자동 판독해 검증하는 기능은 없습니다**
- Google 검색에서 최근 1개월 공식 공지·언론 기사를 직접 찾아 새 자료 URL을 입력 가능
- 선생님은 주제 카드의 **링크 복사** 기능으로 QR코드용 URL을 학생과 공유 가능
- 학생 탐구 카드는 복사, TXT 내려받기, 브라우저 인쇄/PDF 기능 지원
- 학생 이름/학교 정보 수집 없음. 입력한 학습 진행 상태는 브라우저 탭의 sessionStorage에만 보관

## 자료의 시점과 자동 갱신
- \`data.js\`: 2026-11-19까지 확인한 **저장 사례**입니다. 출처 링크는 후속 검증이 필요합니다.
- \`latest.json\`: 초기에는 2026-11-19 기준 수동 선택한 실제 최근 공식자료 7건을 보여 줍니다.
- \`.github/workflows/localcheck-news.yml\`: GitHub Actions가 매일 한국 시각 약 오전 7시에 \`tools/update_news.py\`를 실행하도록 등록했습니다. 공개 Google 뉴스 RSS에서 충북 11개 시·군의 최근 45일 헤드라인·발행기관·날짜·링크만 모아 파일을 갱신합니다.
- 실제 첫 자동 실행 성공 및 GitHub Pages 반영은 아직 검증되지 않았습니다. Google 뉴스 RSS 제공 상태나 GitHub Actions 저장소 정책에 따라 갱신이 실패할 수 있습니다. 실패 시 기존 자료를 유지하며, 사용자는 ‘최근 1개월 기사’ 검색 버튼을 통해 직접 조사할 수 있습니다.
- 자동 수집 자료는 진실 판정이 아니므로, 학생이 **반드시 원문 및 공식기관 공지와 대조**해야 합니다.

## 예시 40분 수업
1. 5분: "음성군만 교육혁신선도지역으로 선정됐을까?"와 같은 주장 예상
2. 8분: 충북교육청 9월·11월 보도자료를 각각 열어 발표 주체와 날짜 기록
3. 10분: "공모 추진"과 "최종 선정"이라는 표현 비교
4. 10분: 사실 여부를 판정하고 근거가 되는 문장 기록
5. 7분: 탐구 카드를 인쇄·공유하고 새로운 탐구 질문 만들기
