# 학생용 뉴스 검색 서버

학생 화면 → 공개 `/api/news` → Google News RSS / Bing News RSS. 브라우저에서는 AllOrigins/GDELT를 호출하지 않습니다. 서버가 고정된 검색 제공처에서 제목·언론사·날짜·원문 링크 RSS를 받고 기존 브라우저 XML 파서가 카드로 표시합니다. 두 제공처 중 기사가 포함된 정상 응답을 먼저 반환하는 곳을 사용하며 `X-News-Provider`로 출처를 표시합니다. 검색으로 찾은 기사는 검증 완료 상태가 아닙니다.

운영 주소: https://localcheck-news-pace33.lejinku.chatgpt.site/api/news

예: `?region=청주시&keyword=인구&category=news`

- 충북 11개 시군과 전체, news/local/business만 허용합니다. 검색어 최대 85자입니다. Google은 최근 30일, Bing은 제공처의 관련도 검색 범위를 사용하므로 기사 날짜를 확인하세요.
- 외부 요청 8초 제한, RSS 650KB 제한, 외부 URL 입력 불가, HTTPS 고정, 리디렉션 불허.
- 허용 브라우저 출처는 `https://pace33.github.io`와 서버 자체입니다. CORS는 인증이나 완전한 오남용 방지가 아닙니다.
- 성공 응답만 5분 캐시합니다. 호스팅에서 캐시를 지원하지 않아도 검색을 계속하며 인스턴스 메모리에 최대 20개 응답을 저장합니다.
- Cloudflare IP 헤더가 있으면 캐시 미적중 요청을 인스턴스별 분당 30회로 제한합니다. 전역 제한은 아니며 대규모 공개 운영 시 플랫폼 WAF/사용량 제한을 별도 설정해야 합니다.
- 오류는 400/403/405/429/502/504로 반환하고 0건 성공 응답으로 바꾸지 않습니다. 앱은 저장 기사와 연결 실패를 구분합니다.
- API 키·학생 계정은 필요 없습니다. 검색어와 지역은 검색 제공처에 전달됩니다. 개인정보를 검색어에 넣지 마세요.

## 재배포

`news.mjs`는 Cloudflare Worker의 기본 fetch 핸들러입니다. Sites 프로젝트 `appgprj_6b0100b4bf088191b0850f7d4343bb2a`에서 같은 소스를 Worker로 배포합니다. 배포 산출물은 `dist/server/index.js`, 프로젝트 식별자는 `.openai/hosting.json`에 둡니다. 사이트 저장소에도 동일 소스를 보관합니다.

Vercel로 이전할 때는 저장소 루트 디렉터리를 `local-check`로 지정하면 `api/news.mjs`가 같은 로직을 실행합니다. 학생용 `live-news.js`의 NEWS_API를 새 서버 주소로 변경합니다. 기존 Gemini API는 별도 기능이며 이 뉴스 검색에는 사용하지 않습니다.

RSS 검색은 가용성이 보장된 유료 검색 API가 아닙니다. 2026-11-21 확인 시 Google RSS는 로컬에서 HTTP 200/28건, 운영 서버에서 HTTP 503이었습니다. Bing 대체 검색은 사용자 승인으로 추가했습니다. 중계 서비스 의존성은 제거했으나 검색 제공처 장애·차단은 여전히 발생할 수 있습니다. 운영 서버의 실제 HTTP 응답과 브라우저 검색을 배포마다 확인하세요. 제공처별 RSS 이용 조건을 확인하고 상업적 서비스 확대 시 정식 라이선스 검색 API로 교체하세요.


## AI 근거 검토 (/api/verify)

- 학생의 최초 기사 검증(출처·근거·첫 판단과 이유)을 완료한 뒤에만 클라이언트가 POST 요청합니다. AI가 검증의 정답을 결정하지 않습니다.
- `server/verify.mjs`는 Gemini Google Search로 실제 검색 근거를 수집하며, 자료 URL을 확보하지 못하면 **확인할 근거가 부족해요**로 응답합니다.
- 환경변수: `GEMINI_API_KEY` (비밀 서버 키), `AI_VERIFY_ENABLED=true` (운영자 명시적 사용 승인), 선택 `GEMINI_MODEL`. 키나 활성화 값이 없으면 503으로 거절합니다.
- Cloudflare Worker 사용 시 `news.mjs`와 `verify.mjs`를 함께 번들링해 재배포해야 합니다. 기존 `/api/news` 기능은 유지됩니다. GitHub Pages에 대한 CORS를 허용합니다.
- Vercel 사용 시 `api/verify.mjs`가 동일 코드를 호출합니다. 기존 Vercel 프로젝트는 별도 배포되어야 합니다.
- 인스턴스별 분당 6회·하루 45회의 제한은 기본 방어이며, **전역 분산 제한이나 인증이 아닙니다.** 공개 학교 서비스에서는 호스팅 플랫폼의 WAF·요금 상한·사용량 제한을 추가해야 합니다.
- 클라이언트가 기사 제목·URL·학생이 작성한 첫 판단·근거 메모를 AI 서버로 보내므로 실명·연락처 등 개인정보 입력 금지를 지도해야 합니다.
- 서비스 연결 불가·시간 초과·자료 부족은 AI 판단 성공으로 표시하지 않으며 학생의 직접 검증 내용으로 최종 판단을 기록할 수 있습니다.
