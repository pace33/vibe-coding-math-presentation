# 우리 지역을 탐정처럼 읽다 — 초등교원 연수 발표 웹앱

## 공개 주소

- 연수용 슬라이드: https://pace33.github.io/vibe-coding-math-presentation/local-check/teacher-training/
- 기존 학생용 웹앱(변경하지 않음): https://pace33.github.io/vibe-coding-math-presentation/local-check/student/

## 운영

- 2026. 11. 25.(수) 15:00–17:00
- 인성교육 현장적용 활동 사례 연구 1
- 연구과제 2. 지역 가치중심 AI 데이터 교육
- 대상: 초등교원
- **구성**: 교육적 필요성 → 교육과정·인성교육 연결 → 웹앱 기능 소개 → 제작 과정을 이미지로 시연 → 초등 수업·평가 적용
- **제작 실습 없음**: 직접 코딩·사이트 생성·로그인·설치·참가자 과제 없이 제작 과정 화면을 정적 SVG 이미지로 보여 줍니다.

## 조작

- ← / →, PageUp / PageDown: 전후 슬라이드
- Home / End: 처음·마지막 슬라이드
- O: 목차
- N: 발표자 메모
- F: 전체화면
- 상단 ‘인쇄·PDF’: 모든 슬라이드를 인쇄하여 PDF로 저장
- 하단 버튼으로도 이동 가능하며, 화면 폭에 따라 자동 반응합니다.

## 자료 정확성 및 주의

- 제작 이미지는 실제 `우리 지역 탐정`의 메뉴·기능·수정 기록을 바탕으로 재구성한 **교육용 예시 이미지**입니다. 실제 뉴스 결과 스크린샷으로 표시하지 않습니다.
- 학생용 웹앱은 충북 11개 시·군, 6개 분야, 뉴스 기사 검색·검증 및 탐정 카드 저장을 제공합니다. 게시판은 기기별 localStorage 방식이며 학급 공동 서버 게시판은 아닙니다.
- 뉴스 서버는 구글 뉴스 RSS와 빙 뉴스 RSS 중 먼저 유효한 응답을 반환한 제공처를 사용합니다. 표시된 정보는 검증 완료가 아닙니다. 외부 링크·방문예약·실시간 운영 상태는 현장에서 원문 확인이 필요합니다.
- 교실 적용 슬라이드의 ‘쉬운 질문 틀, 시각 지원, 다양한 표현’은 **교사 수업 설계 제안**이며 모든 기능이 웹앱에 구현되어 있다고 주장하지 않습니다.
- 교육과정 자료: 교육부 「2022 개정 교육과정 확정·발표」 https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&m=020402&opType=N
- 디지털 소양 자료: 경기도교육청 「2022 개정 교육과정의 디지털 소양 내용 요소와 반영 방향」 https://www.goe.go.kr/resource/old/BBSMSTR_000000000126/BBS_202402261130401580.pdf

## 파일

- `index.html`: 발표 화면/목차/노트 구조
- `style.css`: 16:9 슬라이드 디자인, 모바일 화면, 출력
- `slides.js`: 전체 발표 내용과 발표자 노트
- `app.js`: 키보드 조작, 목차, 발표자 노트, 전체화면, 인쇄
- `assets/01-prompt.svg` ~ `09-visit.svg`: 실제 제작 과정을 재현한 정적 이미지

**주의:** 이 디렉터리는 기존 학생용 `/student/`와 완전히 분리되어 있으며, 발표용 제작 중 학생용 파일을 수정하지 않습니다.
