# 로컬체크 CLASS — 충북 지역정보 탐정 실습실

## 목적
초등 교사 연수에서 **교사가 먼저 정보의 차이·오류를 경험 → 지역 자료를 검색 → 실제 공식 원문을 대조 → 검증 결과를 기록 → 학생의 탐구 수업으로 전환**할 수 있는 정적 웹앱입니다.

## 주소
https://pace33.github.io/vibe-coding-math-presentation/local-check/classroom/

## 실제 데이터
2026-11-17 기준 공개된 공공기관의 충북 11개 시·군 사례 13건을 저장했습니다.
- 교육혁신선도지역: 음성, 제천, 보은 (충북교육청)
- 청주시 인구 통계: 청주시 통계정보시스템, 2차 재게시 자료(원표 교차 검증 필요)
- 지역 축제: 충주, 진천, 괴산, 옥천, 영동, 증평, 단양 (각 지자체 및 문체부)
- 음성군에는 충북 3시 8군의 행정구역 확인 사례도 수록

표시된 기관 자료는 **수업용 저장 사례**이며 자동으로 최신 내용을 받아오는 것은 아닙니다. 학습자는 열람한 원문의 내용을 검토해야 합니다. **'확인됨'은 출처·날짜·내용 체크, 근거 URL, 원문 확인 내용, 판단 이유를 입력한 경우에만 저장할 수 있습니다.** 판정의 정확성을 서버가 보증하지는 않습니다.

## 교사 연수 50분 활용 흐름
1. **5분 — 도입:** ‘2026년 교육혁신선도지역은 음성군만 선정되었다’ 주장 판단
2. **10분 — 자료 검색:** 충북 지역 선택 → 관심 주제 검색 → 공식 원문 열기
3. **20분 — 자료 검증:** 출처·발표일·기준일 확인 → 근거 기록 → 판단
4. **10분 — 동료 비교:** 서로 다른 판단의 근거 비교, 필요한 추가 자료 제시
5. **5분 — 수업 적용:** 학년군 선택 → 학생의 지역 탐구 질문과 활동 만들기

## 개인정보·보안
별도 로그인이나 학생 식별 정보는 받지 않습니다. 사용자의 입력과 검증 결과는 기기 브라우저 localStorage에만 저장합니다. 공유 PC에서는 종료 전 초기화 버튼으로 기록을 지우도록 안내하세요. CSV 내보내기 및 인쇄는 브라우저에서 처리합니다.

## 한계
GitHub Pages는 서버를 실행할 수 없으므로 **전국의 최신 지역 정보를 자동 수집하거나 원문의 실제 내용까지 자동 판독하는 기능을 제공하지 않습니다.** 충북 11개 시·군에 대한 **저장된 실재 자료 검색**과 외부 검색 링크, 교사의 직접 검증 기록 기능을 제공합니다. 추후 서버리스 Gemini/검색 API로 실시간 검색을 연결할 수 있지만 API 키·비용 관리가 필요합니다.
